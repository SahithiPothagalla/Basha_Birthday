BASHA BIRTHDAY SURPRISE WEBSITE
================================

Open index.html in a modern browser.

Included:
- Cinematic intro
- Cricket / mindset chapter
- Hero + director movie-poster chapter
- Six-photo memory gallery
- Personalized birthday letter
- Hidden final message
- Animated birthday finale
- Mobile responsive design

To customize:
1. Open index.html in VS Code or another editor.
2. Replace text such as "BASHA" with his preferred name if needed.
3. Replace files inside assets/ with your own photos while keeping the same filenames.
4. Optional music: add birthday-music.mp3 to the project and connect it in the JavaScript section.

The site is intentionally self-contained apart from the Google Fonts import.
